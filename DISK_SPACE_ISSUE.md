# ⚠️ КРИТИЧЕСКАЯ ПРОБЛЕМА: НЕТ МЕСТА НА ДИСКЕ

## 🚨 Проблема

**Свободно места:** 5.4 GB  
**Требуется для сборки:** 15-20 GB минимум

### Ошибки
```
error: couldn't create a temp dir: No such file or directory
SIGKILL (signal 9) - нехватка памяти/места
```

## 💡 Решения

### 1. Освободить место (БЫСТРО)

```bash
# Очистить кэш cargo
cargo clean

# Очистить кэш Homebrew
brew cleanup

# Удалить старые iOS симуляторы (если есть)
xcrun simctl delete unavailable

# Проверить что занимает место
df -h /
ncdu /
```

### 2. Использовать онлайн компилятор

**Варианты:**
- GitHub Codespaces (бесплатно 60 часов/месяц)
- Gitpod
- Replit

### 3. Собрать на другом компьютере

### 4. Использовать минимальную сборку

Создам супер-минимальный Cargo.toml:

```toml
[package]
name = "ant-minimal"
version = "0.9.0"

[dependencies]
tokio = { version = "1", features = ["full"] }
serde = { version = "1.0", features = ["derive"] }
anyhow = "1.0"
ratatui = "0.26"
crossterm = "0.27"
```

**Время сборки:** ~3-5 минут  
**Место:** ~2-3 GB

## 📊 Требования к ресурсам

| Компонент | Место | Время |
|-----------|-------|-------|
| **Минимум** | 10 GB | 5-10 мин |
| **Рекомендуется** | 20 GB | 10-20 мин |
| **Полная сборка** | 30+ GB | 40-60 мин |

## 🎯 Текущий статус

**Нельзя продолжать сборку** пока не освободите место!

## ✅ Что делать прямо сейчас

1. **Очистить диск:**
   ```bash
   cargo clean
   rm -rf ~/Library/Caches
   ```

2. **Проверить место:**
   ```bash
   df -h /
   ```

3. **Если < 10 GB:**
   - Удалить большие файлы
   - Переместить данные на внешний диск
   - Использовать другой компьютер

4. **Если > 10 GB:**
   ```bash
   cargo build --release
   ```

## 🚀 Альтернатива: Docker

```bash
# Создать Docker контейнер с большим диском
docker run -it --rm -v $(pwd):/app rust:latest bash
cd /app
cargo build --release
```
